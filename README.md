# Exp4MLCourse 项目总结

本项目包含一系列关于**图像恢复**与**鲁棒性分类**的实验，主要利用 **AdaIR** 和 **Mamba (状态空间模型)** 等先进架构来应对图像腐蚀问题。

---

## 1. 实验一：AdaIR 基准与鲁棒性测试
**目录**: `code/exp1`
**模型权重**: [Google Drive 下载](https://drive.google.com/file/d/1ouweWECtch_pGtqgLy933bpT4xNf45KJ/view?usp=drive_link)

### 1.1 实验目的
评估现有图像恢复模型（**AdaIR**）在面对常见图像腐蚀时的鲁棒性，并量化其对下游分类任务（使用 VGG16）准确率的影响。

### 1.2 实验方法（模型架构）
*   **核心模型**: `AdaIR` (Adaptive Image Restoration)。
*   **工作流**:
    1.  输入退化图像 (来自 ImageNet-C)。
    2.  使用预训练的 AdaIR 模型恢复图像。
    3.  将恢复后的图像输入标准的 VGG16 分类器。
*   **数据集设置**: 测试了 6 种场景：Contrast (对比度), Fog (雾), Motion Blur (运动模糊), Snow (雪), Brightness (亮度) 和 Origin (原始清晰图像)。

### 1.3 实验结果
**数据来源**: `code/exp1/results/test_results_20260124_065023.txt`

| 腐蚀类型 (Corruption) | PSNR | SSIM | 原始准确率 (Orig Acc%) | 恢复后准确率 (Enh Acc%) | 提升情况 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Contrast** | 23.24 | 0.8054 | 29.94% | 47.70% | **+17.76%** |
| **Fog** | 19.95 | 0.7810 | 37.19% | 55.65% | **+18.46%** |
| **Motion Blur** | 25.89 | 0.7948 | 28.32% | 48.25% | **+19.93%** |
| **Snow** | 24.74 | 0.7939 | 23.02% | 52.71% | **+29.69%** |
| **Brightness** | 24.02 | 0.8414 | 60.75% | 63.70% | +2.95% |
| **Origin (Clean)** | 22.78 | 0.9104 | 71.04% | 69.97% | -1.07% |

*   **总结**: 在严重腐蚀场景（如雪、雾）下有显著提升，但在清晰图像上会有轻微的性能损失。

## 2. 实验二：基于 Mamba 的特征增强
**目录**: `code/exp2`
**模型权重**: [Google Drive 下载](https://drive.google.com/file/d/1SdHGg5Hqj7GMYTWsIFmzBWi2qtcxv-ya/view?usp=drive_link)

### 2.1 实验目的
提出一种计算高效的**特征级增强**模块，利用 **Mamba (State Space Models)** 的长距离建模能力，直接在分类器的特征层修复退化，作为全图像恢复的更高效替代方案。

### 2.2 实验方法（模型架构）
*   **核心模型**: `MambaFeatureEnhancer` (位于 `archs/feature_mambair.py`)。
*   **架构创新**:
    *   **FDM 级联设计**: 采用受 FDM 启发的三分支级联结构 (中心 -> 环绕 -> 边缘) 逐步处理特征。
    *   **VSS Block**: 集成 **Visual State Space (Mamba)** 模块，以线性复杂度实现全局感受野。
    *   **全局校正 (Global Correction)**: 添加轻量级模块以修正全局统计量（亮度/对比度）。
    *   **融合机制**: 融合多分支输出并以残差形式叠加到原始退化特征上。

### 2.3 实验结果
**数据来源**: `code/exp2/results/test_results_20260122_134332.txt`

| 腐蚀类型 (Corruption) | 原始准确率 (Orig Acc%) | 增强后准确率 (Enh Acc%) | 准确率差值 (Diff) |
| :--- | :--- | :--- | :--- |
| **Contrast** | 29.94% | 45.55% | **+15.61%** |
| **Fog** | 37.18% | 52.64% | **+15.46%** |
| **Motion Blur** | 28.32% | 35.70% | +7.38% |
| **Snow** | 23.02% | 41.32% | **+18.30%** |
| **Brightness** | 60.75% | 62.51% | +1.76% |
| **Origin (Clean)** | 71.04% | 70.74% | -0.30% |

*   **总结**: 平均在腐蚀数据集上带来了 **+11.70%** 的准确率提升，且在清晰图像上的性能损失极小 (-0.30%)，证明了 Mamba 模块的高效性与安全性。

## 3. 实验三：基于特征的图像重建 (Decoder)
**目录**: `code/exp3`
**模型权重**: [Google Drive 下载](https://drive.google.com/file/d/16somLoGmUEoGfBYSovSyYUw7zD9z7F-g/view?usp=drive_link)

### 3.1 实验目的
验证 Exp2 中增强后的特征是否保留了足够的语义与空间细节。通过将特征重新解码为可视图像，定性与定量地分析特征增强的质量。

### 3.2 实验方法（模型架构）
*   **核心模型**: `FeatureDecoder` (位于 `archs/decoder.py`)。
*   **架构细节**:
    *   **输入**: 来自 VGG Block 1 的增强特征 (128通道, 56x56分辨率)。
    *   **特征精炼**: 使用带**通道注意力 (SE)** 的残差块。
    *   **上采样**: 采用 **Pixel Shuffle** (x4 上采样) 替代传统的双线性插值，以生成更锐利、细节更丰富的 224x224 图像。
*   **流程**: 退化图像 -> Mamba 增强器 (Exp2) -> 特征解码器 (Exp3) -> 重建图像。

### 3.3 实验结果
**数据来源**: `code/exp3/results/test_results_20260124_021730.txt`

| 腐蚀类型 (Corruption) | 重建 PSNR (dB) | 重建 SSIM | 原始准确率 (Orig Acc%) | 增强后准确率 (Enh Acc%) |
| :--- | :--- | :--- | :--- | :--- |
| **Contrast** | 20.60 | 0.7706 | 29.94% | 42.99% |
| **Fog** | 17.82 | 0.7405 | 37.19% | 51.22% |
| **Motion Blur** | 22.55 | 0.6969 | 28.32% | 32.93% |
| **Snow** | 21.92 | 0.7289 | 23.02% | 38.93% |
| **Brightness** | 20.61 | 0.7794 | 60.74% | 61.22% |
| **Origin (Clean)** | 28.86 | 0.9030 | 71.04% | 69.44% |

*   **总结**: 
    *   **视觉质量**: 清晰图像的重建 PSNR 达到 **28.86 dB** (SSIM 0.90)，证明了解码器具有很高的还原能力。
    *   **语义一致性**: 重建图像的分类准确率 (69.44%) 与原始图像 (71.04%) 非常接近，表明 Mamba 增强后的特征完整地保留了用于分类的关键语义信息。
